## 关于我

我是 **ShenGeYan / 沈歌宴**，一名 **Web 前端开发者**，也是 **重庆理工大学计算机科学与技术专业** 的学生。

我喜欢清晰、流畅、真正有用的界面，也关注前端工程化、产品交互、AI 辅助开发，以及能让创作流程更顺手的小工具。

- 使用 **Vue 3**、**React**、**TypeScript** 构建前端应用。
- 探索 **SSR**、**SEO**、资源平台、协同工具和机器人工作流。
- 把灵感实验沉淀成结构清楚、细节可靠、可持续维护的项目。
